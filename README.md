# Handwritten Urdu Character Recognition System Using CNN

## Overview

This project is a Handwritten Urdu Character Recognition System developed using Convolutional Neural Networks (CNN). The system is capable of recognizing handwritten Urdu characters from an input image and predicting the corresponding character with confidence score.

## Features

- Urdu Character Recognition
- CNN-Based Deep Learning Model
- Image Upload Functionality
- Prediction with Confidence Score
- User-Friendly GUI Dashboard
- Accuracy and Loss Visualization
- Model Evaluation

## Technologies Used

- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
- Tkinter

## Dataset

- Total Classes: 40 Urdu Characters
- Training Images: 28,328+
- Dataset Type: Handwritten Urdu Characters

## Model Performance

- Training Accuracy: 98%+
- Validation Accuracy: 93.71%
- Loss: 0.27
